
How to make new source?
    - copy ./map_app/sources/example.disable.py to  ./map_app/sources/<new_name>.py  (or choose more specific example_*.py.d)
    ! Name of file have to be same like name of class (rename Example)
    - use __requirements__ to set requirements names (now it si only for description, will be later used for auto install)



	- Use function config_path(config_name=(default is SOURCE_NAME)) to get config path for Source class
    Source class -> config_path() -> config_name
    - <config_name>.ini
        [tool_name]
        <param_name> = <param_value>


    - if you want create param for tool (typical get_tool function):
	    def get_tools(self):
            config = configparser.ConfigParser()
            config.read(self.config_path())
            wigle_param = [("<param_name>", str, None | validation_function , config['wigle_locate'][<param_name>], "Info about param")]

        return {"wigle_locate":{"params":wigle_param}}

        - validation_function is function what have one param - input string
